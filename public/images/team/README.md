Ketentuan foto:
- Rasio 1:1 (persegi), minimal 400x400 px.
- Format JPG, PNG, atau WebP. Kalau pakai PNG/WebP, ubah juga ekstensinya di `teamData.js`.
- Usahakan ukuran file di bawah 300 KB supaya halaman cepat dimuat.

Kalau foto belum ada, halaman Team otomatis menampilkan inisial nama.
