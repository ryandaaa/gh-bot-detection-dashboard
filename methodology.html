Section 03

Data Engineering (MongoDB)

WiredTiger Aggregation

Due to the multi-gigabyte magnitude of uncompressed GitHub activity events, high-throughput MongoDB ingestion pipelines utilize grouped aggregation operators, secondary indices on actor.id, and multi-stage transformations:

// Multi-stage aggregation snapshot
db.events.aggregate([
  { $match: { "created_at": { $gte: ISODate("2024-01-01T00:00:00Z") } } },
  { $group: {
    _id: "$actor.id",
    total_events: { $sum: 1 },
    push_count: { $sum: { $cond: [{ $eq: ["$type", "PushEvent"] }, 1, 0] } },
    distinct_repos: { $addToSet: "$repo.id" },
    timestamps: { $push: "$created_at" }
  }},
  { $project: { actor_id: "$_id", total_events: 1, push_ratio: { $divide: ["$push_count", "$total_events"] } } }
]);
Section 04

11 Behavioral Features

Actor Feature Vector

Rather than relying solely on raw frequency counting, we construct an 11-dimensional behavioral signature capturing temporal regularity, burstiness dynamics, and target repository entropy.

1. Event Volume Count

Total count of public actions recorded for the actor within observation window.

Scale: Log-normalized transformed · Minimum inclusion threshold: >5 events.
2. Event Diversity Entropy H(E)

Shannon entropy of event types: -∑ p(e) log2 p(e) across 14 event classes.

High diversity reflects balanced workflow (PR review, issues, releases, pushes).
3. Push Ratio % (0.0 - 1.0)

Proportion of events strictly tagged as PushEvent relative to all actions.

Automated continuous sync scripts typically exhibit Push Ratio >0.98.
4. Repository Concentration Herfindahl Index

Measurement of event distribution across target repositories.

Values near 1.0 denote single-repo focus; lower values indicate multi-repo propagation.
5. Active Hour Coverage % (0.0 - 1.0)

Ratio of distinct clock hours (0–23 UTC) containing at least one recorded event.

Exceeding 85% active hours strongly flags automated or multi-user bot tokens.
6. Hour Entropy H(Hour)

Dispersion measure of activity timestamps across 24-hour diurnal diurnal cycles.

Human operators exhibit heavy diurnal concentration aligned with timezones.
7. Burstiness Index B ∈ [-1, 1]

Goh-Barabasi burstiness coefficient computed from inter-arrival event deltas.

B = (σ - μ) / (σ + μ). Bots tend toward periodic (-1) or hyper-bursty (+1).
8. Inter-event Time Variance Var(Δt)

Variance of elapsed seconds between sequential actions by the same actor.

Cron jobs trigger zero-variance peaks at exact modulo intervals (300s, 3600s).
9. Temporal Regularity Autocorr

Lag-1 autocorrelation of event frequency intervals over 60-minute buckets.

High coefficients correspond to deterministic periodic script executions.
10. Type Entropy Normal H

Normalized entropy of payload types excluding high-frequency automated pushes.

Reveals whether multi-event actors genuinely engage in social coding interactions.
11. Repository Entropy H(Repo)

The dispersion profile across all targeted repositories, indicating whether activity is focused on a dedicated project or scattered systematically across multiple external forks.

Crucial differentiator between focused maintainers versus broad-spectrum campaign accounts.

Machine Learning Modeling

Dual Unsupervised Architecture
filter_alt Isolation Forest

Computes anomaly depth scores by measuring tree isolation depth across hyper-planes.

Trees (n_estimators): 250
Contamination param: 0.021 (~2.1%)
Max sample split: auto (256)
Output: Anomaly score ranging from 0.0 (strictly nominal) to 1.0 (anomalous).
bubble_chart K-Means Clustering

Partitions nominal behavioral vectors into four distinct archetype cohorts.

Centroids (k): 4 Clusters
Initialization: k-means++
Convergence tolerance: 1e-4
Cohort Taxonomy: C0 (Standard), C1 (Single-Repo), C2 (Continuous CI), C3 (Poly-repo).

Section 07

Privacy, Ethics & Boundaries

Ethical Guidelines
Pseudonymous Storage & Hash Identification

All actor login handles and account names are decoupled from the research vectors. Internal models identify entities strictly via deterministic numeric actor identifiers (actor.id). Personal identity records, email metadata from commit headers, and commit message text payloads are deliberately dropped prior to storage ingestion.

Offline Dataset Boundaries

This intelligence environment evaluates observation data strictly bounded by the archived 152-hour window. On-demand real-time API queries are intentionally unlinked from production GitHub credentials to prevent non-consensual tracking. Inquiries on accounts outside observation blocks will yield deliberate Not observed states.

Non-Punitiveness of Anomaly Scores

An elevated anomaly index is an empirical indicator of statistical behavioral novelty (such as CI orchestrators, university teaching mirrors, or synchronized bot tools), not an allegation of malicious conduct or violation of GitHub Terms of Service.
